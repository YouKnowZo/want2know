What it does

Want2Know by PaperBagExpress is an OSINT (Open Source Intelligence) tool that searches for a username across 1000+ social media platforms, forums, gaming networks, and more. It only checks publicly accessible URLs — no login, no scraping, no hacking.

Features
Profile search across 1000+ platforms
Fast scan with confidence scoring
Phone number intelligence
IP & domain geolocation
WHOIS domain lookup
CSV & JSON export
Dark mode toggle
Search history
Rate limiting protection
Result persistence
Understanding Results

The confidence score (0–100%) reflects how likely a profile belongs to the searched username — it is not a guarantee. Common usernames may match many unrelated accounts. Always verify manually before drawing conclusions.
